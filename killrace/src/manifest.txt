# KILL RACE build manifest. Same format as bagman/src/manifest.txt.
#
# Kill Race is built on the BAGMAN engine. Every ../../bagman/ line below is a
# Bagman engine file used unchanged: the palette and CRT pipeline, asset
# loading, audio, the floor caster, sprites and particles, and the whole
# on-foot enemy AI (deputies and dogs on the sidewalks are Bagman enemies).
# The js/ lines after them are the car game. All of it shares one scope, so a
# Bagman file that calls hurtPlayer(), hurtEnemy(), wake(), carHit() or
# detonate() gets the versions defined in js/game/damage.js.
#
# Every asset comes from Bagman's asset table; Kill Race adds no art or sound.
