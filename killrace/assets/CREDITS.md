# Kill Race: third-party assets

Kill Race's art is BAGMAN's (see `../../bagman`). This folder adds sound,
music and one sprite from free sources. Every file below was converted, never
edited: sounds to mono 22 kHz WAV/MP3, music to 96 kbps MP3. The explosion's
nine PNG frames are laid side by side in one strip. All were fetched through
GitHub mirrors on 2026-10-07; the upstream page is the original source.
