# Houdini games

| Folder | What | Stack |
|---|---|---|
| [`bagman/`](bagman/) | **BAGMAN**, released. A ZX Spectrum styled raycaster shooter set in Nevada. Ships as one HTML file. | JavaScript, WebGL, WebAudio. Node build script, no dependencies. |
| [`invaders-ds/`](invaders-ds/) | Space Invaders, a remake of the Atari 2600 version for the Nintendo DS, in progress. | C, libnds, BlocksDS |

Each folder has its own README with build steps.
